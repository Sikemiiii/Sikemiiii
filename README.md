##  Featured Projects

### [Mini-Aaru](https://github.com/Sikemiiii/mini-aaru)
LLM-powered behavioural user modeling and recommendation system. Ingests Yelp, Amazon, and Goodreads data to build user personas and simulate authentic Nigerian reviews — including a Nigerian Context Layer with pidgin-aware outputs. Built with LangChain, FastAPI, Groq, and Docker. Live at [mini-aaru-production.up.railway.app](https://mini-aaru-production.up.railway.app/docs).

### PIML Gas Detection (Final Year Project)
LSTM-based predictive model for hazardous gas detection using Physics-Informed Machine Learning. 98.12% accuracy on industrial sensor datasets. Built with Python, TensorFlow/Keras.
